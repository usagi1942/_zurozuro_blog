正當 AI 大戰繼續喺戰國時代，七國咁亂之際，突然又跑出一個叫TypeSafe Jev 既 classification model 成為炙手可熱既新貴，風頭一時無兩。

我明白F老既質疑。因為如果數番轉頭 machine learning classification 本來就唔係咩新事物，就算舊時咩logistic model 咩perceptron 都一律算數。太陽底下果然已無新事。而果然話口未完，過多一個時期左右，已經有人開始用 LLM 煲番轉頭將佢變成好似 Jev 咁樣只答是非同多項選擇題，或者出現 Jev 既諸多變體，好似效能又繼續唔知點樣再提升 n 倍。

我自己個人用家意見，覺得依家同舊時長途電話割喉大戰差唔多，總之為左搶市佔就會無所不用其極。AI 都係一樣，除左要佢再聰明啲，幻覺再少啲之外，最緊要愈平、愈快，就愈好。Jev 打住一個好低成本既高效分類操作，對硬體要求亦都唔大，當然會有一定既噱頭。

就好似我諗到既一啲 Use case ，例如要將幾百萬個text row 做 data label ，依家一係就自己執左offsite LLM 自己走，但如果無黃生GPU係會走成世都未做完。而我地又唔可以將個 file 就咁就 upload 上去AI platform 因為一樣唔知要燒幾多個 token 先完成個任務。但係用呢啲 Jev system 1，時間快，而且只係駛幾蚊美金，咁一試又何妨。

況且依家 AI 更迭速度快到痴線。隨時好似龍蝦咁，都唔知捱唔捱到一頭半個月，可能又已經比另一個 model 取代…
