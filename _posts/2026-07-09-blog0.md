一貶個眼，我用 Github 寫野都兩三個月啦，單純講下感受。

完全無人睇既野，真係好似寫緊毒撚日記咁。雖然的確係無乜所謂（放出公海亦都唔代表有人睇，你又唔係 Double May），但無左留言區，無得即時交流吹廢水，就會悶多些少（好似 Github 都有 Template 可以搞到訪客留言既，不過我就無心機去鑽研，另外依家啲文慢慢增加緊但我都未整個下一頁既按鈕，所以個主頁會隨時間愈黎愈長 LOL）。

我甚至懷疑 f0 部隊都無咩睇，成功爭取將呢度變成一部回音牆 LOL。

另外，Github 寫野，始終都唔會好似 Threads 或者 Wordpress 咁直接了當。結果每次我都要用個Text editor 先寫好正文，儲起佢，再喺個介面開新純文字檔案，仲要加番一堆 Header 然後再做複製同貼上。雖然都係幾個 Step ，但總會覺得無咁順手：之前明明就喺一個 Text box 打完然後 Submit 就搞很掂食碗麵。

因為啲野唔夠就手，就變相令到我拖延症有所發作。本來一日寫一篇，就變左一個星期儲好一堆話題先一次過寫，然後先去 Github 一口氣更新晒咁多篇文。所以從呢方面你就可以睇到， user interface design 係咁重要呢。

雖然係咁，寫下文都係一件好事黎。尤其是依家好似愈黎愈多文同片都係 AI Gen，睇下睇下撞鬼都覺得真係好鬼悶，完全唔想再睇落去。我地距離 Matrix 世界究竟仲有幾遠？如果有得揀既話，可唔可以搞到個刀劍神域先唔該。Bang
